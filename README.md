## About the Project

This is my personal portfolio website, built to showcase my web development skills, selected projects, creator collaborations, and a little about my journey beyond the screen.

The website is a work in progress, and I will continue improving its design, content, and functionality.

## Features

- Personal introduction and profile section
- Skills overview
- Web development project cards
- Creator project showcase with video previews
- About Me section
- Contact form
- Navigation links to different sections of the page
- Hosted with GitHub Pages

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling and layout
- **JavaScript** — interactive functionality
- **GitHub Pages** — website hosting

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/aalokking01/myportfolio.git
   ```

2. Open the project folder:

   ```bash
   cd myportfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Deployment

This website is published using GitHub Pages.

**Live URL:** https://aalokking01.github.io/myportfolio/

To publish updates, commit and push the changed files to the repository's configured publishing branch. GitHub Pages will deploy the latest version.
